## Tech Stack

- **Frontend**: HTML/CSS/JS, React (CDN), Tailwind CSS
- **Backend**: Node.js, Express
- **Database**: PostgreSQL (Supabase)
- **Auth**: JWT + bcrypt
- **AI**: OpenAI API
- **Deploy**: Vercel
- **Tools**: MCP (Notion, Chrome)
