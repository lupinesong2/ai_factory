## 떡볶이 기본 레시피 (2인분)

### 재료
- 떡볶이떡 300g
- 어묵 2장
- 대파 1/2대
- 물 2컵 (400ml)

### 양념
- 고추장 2큰술
- 고춧가루 1큰술
- 설탕 1큰술
- 간장 1큰술
- 다진마늘 1/2큰술

### 만드는 법
1. 떡은 찬물에 5분 정도 담가 부드럽게 준비
2. 어묵은 먹기 좋은 크기로 썰고, 대파는 어슷 썰기
3. 냄비에 물 2컵 + 양념 재료를 넣고 끓이기
4. 양념이 끓으면 떡과 어묵을 넣고 중불에서 5~7분 조리
5. 대파를 넣고 1~2분 더 끓이면 완성

## 응용 레시피 모음

### 1. 로제 떡볶이 (2인분 / 20분)

#### 재료
- 떡볶이떡 300g, 어묵 1장, 소시지 8개, 베이컨 2줄
- 양파 1/2개, 대파 1/2대, 청양고추 1개
- 중국당면 30g (선택)

#### 소스
- 토마토소스 6큰술
- 생크림 200ml + 우유 200ml
- 고추장 1큰술, 고운 고춧가루 1큰술
- 버터 1큰술, 다진마늘 1/2큰술
- 카레가루 1/4큰술, 진간장 1작은술, 올리고당 1큰술
- 파르메산치즈 2큰술

#### 만드는 법
1. 당면은 물에 불리고, 떡은 헹궈서 물기 제거
2. 소시지에 칼집, 베이컨은 굵게 채 썰기, 어묵은 떡 크기로 자르기
3. 팬에 버터 → 다진마늘 + 양파 + 베이컨 볶기
4. 토마토소스 + 고추장 + 고춧가루 + 카레가루 넣고 볶기
5. 우유 + 생크림 부어 소스 만들기
6. 떡 + 어묵 + 소시지 + 당면 넣고 떡이 말랑해질 때까지 중불 5~7분
7. 파르메산치즈 뿌려 마무리

> TIP: 생크림 없으면 우유 400ml + 카레가루로 대체 가능

---

### 2. 크림 떡볶이 (2인분 / 15분)

#### 재료
- 떡볶이떡 300g, 베이컨 3줄, 양파 1/2개
- 우유 300ml (또는 생크림 200ml + 우유 100ml)
- 버터 1큰술, 다진마늘 1/2큰술
- 소금 약간, 후추 약간, 파슬리 (선택)

#### 만드는 법
1. 팬에 버터 → 베이컨 노릇하게 볶기
2. 양파 + 다진마늘 추가하여 투명해질 때까지 볶기
3. 우유(또는 생크림+우유) 부어 끓이기
4. 떡 넣고 중불에서 5~7분 졸이기
5. 소금 + 후추로 간 맞추고 파슬리 뿌려 완성

> TIP: 맵지 않아 어린이 간식으로 추천

---

### 3. 짜장 떡볶이 (2인분 / 20분)

#### 재료
- 떡볶이떡 200g, 어묵 80g, 대파 1/2대, 삶은 달걀 2개

#### 양념
- 물 1.3컵, 짜장소스(춘장) 1/2컵
- 설탕 1큰술, 고추장 2/3큰술

#### 만드는 법
1. 냄비에 물 + 짜장소스 + 설탕 + 고추장 넣고 잘 풀기
2. 떡 + 삶은 달걀 넣고 끓이기
3. 소스가 졸아들면 대파 + 어묵 추가
4. 2~3분 더 졸이면 완성

> TIP: 어묵은 처음부터 넣지 말 것 (너무 물러짐). 짜파게티 스프 활용도 가능

### 4. 궁중 떡볶이 (2인분 / 20분)

#### 재료
- 떡볶이떡(가래떡) 300g, 소고기 100g, 당근 1/4개
- 양파 1/2개, 표고버섯 2개, 피망 1/2개, 대파 1/2대

#### 양념
- 간장 3큰술, 설탕 1큰술, 참기름 1큰술
- 다진마늘 1/2큰술, 깨소금 약간, 후추 약간

#### 만드는 법
1. 소고기와 채소를 모두 채 썰기
2. 소고기에 간장 1큰술 + 참기름 + 후추로 밑간 (10분)
3. 떡은 끓는 물에 살짝 데쳐 부드럽게 준비
4. 팬에 참기름 → 소고기 볶기 → 채소 추가 볶기
5. 떡 + 나머지 양념 넣고 중불에서 볶기
6. 간 맞추고 깨소금 뿌려 완성

> TIP: 안 매워서 호불호 없음. 아이 간식, 명절 음식으로 추천

### 5. 마라 로제 떡볶이 (2인분 / 15분)

#### 재료
- 떡볶이떡 200g, 어묵 100g, 분모자 100g
- 돼지고기 100g, 양배추 100g, 청경채 30g
- 대파 30g, 흰목이버섯 50g, 양파 1/4개

#### 소스
- 마라소스 90~120g (매운맛 조절)
- 생크림 250g

#### 만드는 법
1. 채소 큼직하게 썰고, 목이버섯 불려서 먹기 좋게 자르기
2. 돼지고기에 소금 + 후추 밑간 후 팬에 볶기
3. 고기가 익으면 양파 + 대파 추가 볶기
4. 마라소스 넣고 향 올리기
5. 생크림 부어 소스 만들기
6. 떡 + 어묵 + 분모자 + 채소 넣고 5분 끓이면 완성

> TIP: 마라소스 양으로 매운맛 조절. 중국당면 추가하면 더 풍성

### 6. 기름 떡볶이 (2인분 / 10분)

#### 재료
- 떡볶이떡 300g, 어묵 2장, 대파 1/2대

#### 양념
- 식용유 2큰술, 참기름 2큰술
- 고춧가루 2큰술, 진간장 1큰술, 설탕 1큰술

#### 만드는 법
1. 팬에 식용유 + 참기름 두르기
2. 떡 넣고 겉면이 노릇해질 때까지 볶기
3. 고춧가루 + 간장 + 설탕 넣고 빠르게 볶기
4. 어묵 + 대파 넣고 1~2분 더 볶으면 완성

> TIP: 국물 없이 볶는 스타일. 빠르게 만들 수 있어 야식으로 추천
